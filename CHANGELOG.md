# Changelog

## 2.0.0

- Supports PES 2016, 2017, 2019, 2020 and 2021 in one app, renamed from PES 2017 Music.
- Finds installed games and switches between them.
- The mod now ships only the files it changes, so it leaves DLC data alone.
- Installs made with PES 2017 Music 1.0.0 are recognised and upgraded.
- Mods are registered with a version the game accepts.

## 1.0.0

- PES 2017 only, released as PES 2017 Music.
